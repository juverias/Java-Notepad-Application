# Java Swing Notepad Editor

A lightweight desktop text editor developed using **Java 21** and **Java Swing**. This application provides essential notepad functionality through a simple, intuitive graphical user interface, allowing users to create, open, edit, and save text files.

## Features

- **Create New Files:** Start writing in a new document.
- **Open Files:** Browse and open existing text files.
- **Save Files:** Save your work to the desired location.
- **Text Editing:** Write, modify, and manage text easily.
- **Graphical User Interface:** Simple and user-friendly interface built with Java Swing.
- **Custom Application Icon:** Includes a custom notepad application icon.
- **Executable JAR:** Run the application independently without opening the project in an IDE.

## Technologies Used

- **Programming Language:** Java 21
- **GUI Framework:** Java Swing
- **IDE:** Eclipse
- **Application Packaging:** Executable JAR

## Requirements

- Java Runtime Environment (JRE) or Java Development Kit (JDK).
- Java 21 recommended.

## How to Run

### Option 1: Run the Executable JAR

1. Navigate to the [Releases](../../releases) section.
2. Download `NotepadEditor.jar`.
3. Ensure Java is installed on your system.
4. Double-click the JAR file to launch the application.

### Option 2: Run from Eclipse

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project as an existing Eclipse project.
4. Locate the main Java class.
5. Run the application.
